# Personalised one-sheets, hand-delivered, instead of a generic door-drop

The first outreach wave is a printed one-sheet made for one named business,
showing that business's own concept, and handed to the owner in person during
trading hours. There is no untargeted door-drop: the shortlist is nine
businesses in two small towns, so cost-per-door — the only argument for mass
delivery — carries no weight, and a generic flyer cannot climb the first rung
of the belief ladder in PRODUCT.md ("the studio understands this place")
because it does not know whose door it is at.

## Considered options

PLAN.md originally recommended the reverse: a generic A5 bifold as the primary
drop with personalised sheets as a follow-up for priority names. Also weighed
were an A6 proof postcard, a multi-panel street sampler, and a window-ready
mini-poster. All four share the defect that they explain the offer rather than
show it, and a folded flyer through every door is structurally the junk mail
PRODUCT.md's anti-references warn against.

## Consequences

- Delivery is a conversation, not a drop. The disclosure that the concept is
  independent and uncommissioned gets said out loud, so the paper carries less
  of that burden than a letterbox piece would.
- Nine doors is a small sample, and the compensation is that each one returns a
  reason rather than a silence. That only pays off if the walk is done in
  person.
- The first batch is the Dundrum walk — Buck's Head, Scopers, Cúpla — with
  Enniskeen held for batch two. Batch one's purpose is to teach the
  conversation, and the flagship is the highest-stakes room on the list; it
  should not be spent on an unrehearsed opener.
- M3 does not wait for the F2 Buck's Head film. A published concept plus its M2
  second asset is enough for a one-sheet; if F2 lands first it enriches that
  sheet, and if it does not the sheet ships regardless.
- Revisit the door-drop only if the named wave under-converts.

## Outcome update — 27 July 2026

The Buck's Head was contacted before the three-sheet walk. A director replied
that a new website has already been built and will launch when the
accommodation is ready. The reply establishes no current redesign opportunity;
it is not recorded as a rejection because it did not decline future contact.

The Buck's Head leaves the active first wave and its one-sheet will not be
sent. Scopers and Cúpla remain the first-wave conversations. No replacement is
added simply to restore the original batch size. The public Buck's Head concept
remains dated portfolio work and must be re-reviewed against the replacement
site before any later outreach.
