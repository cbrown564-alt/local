## Who the copy addresses

Guest copy addresses the **owner**. **Visitor** cost is the evidence — the
person with an errand outside the door. See `docs/CONTEXT.md`. Do not use
*stranger* on these pages (it collided with “cold prospect” elsewhere).

## Voice rules

1. **Owner first, visitor-cost as proof.** Not a lecture about the studio method.
2. **Keep honesty constraints; kill the lecture.** Still: invented mocks only, no prevalence claims, no scoring the reader, no real business’s snag on a public page. Do not narrate “step N of the research method,” “not a census,” or “things this page never does” to the guest. One light invented-mock line in the hero is enough; the rest lives in briefs, tests, and comments.
3. **Cut “What this is for.”** Checklist (where it exists) and the close carry the takeaway. One short line may sit in the close if a page feels abrupt.
4. **Almost no method nouns on the guest surface.**

| Old (guest-facing) | Use instead |
| --- | --- |
| fault | what goes wrong / the snag |
| layer | part (of the site) |
| assembly | how it’s put together / the build |
| shape (as taxonomy noun) | avoid; type name or “your kind of site” |
| wireframe | made-up phone / grey layout |
| register | cut; say what the visitor is there to do |
| Fix it | keep |

Studio docs, code identifiers, and `docs/CONTEXT.md` may still say fault /
shape / layer / method.

5. **On Why it’s yours:** type names stay (*a place*, *a counter business*, …).
   The **owner question leads** each plate; the type name is secondary.
6. **Keep the teeth.** Specific visitor costs, the swap test, the “grey runs
   out” stop, no score/grade. Warm the wrapping voice; do not sand into generic
   agency reassurance.
7. **Full surface.** Every guest-visible string on the three pages and their
   data modules gets this voice — not only heroes.

## What the briefs still own

Interaction design, reel/build behaviour, reduced-motion settled frames, theme
ids, invented-mock rules, prevalence prohibition, request-path priority, and
cross-page data sharing. When a brief’s working headline or “what this is for”
prose conflicts with this note, **this note wins for guest copy.**
