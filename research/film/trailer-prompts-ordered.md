# Trailer — the eighteen prompts, in order

*10 August 2026. Copy-paste, in play order, against
`../../media/narration/trailer/trailer-trim.mp3` (1:35.6). Every prompt is
self-contained: the style block and the canonical descriptions are repeated
verbatim in each one on purpose. **Do not reword them between shots** — that
repetition is the only thing keeping the eighteen frames in the same world.*

**Two shots are holds and need no generation** (02 and 14). Sixteen to make.

**All eighteen are generated fresh as stills.** The existing clips — T01, T04,
T05, T10, X18 — stay as *look reference* only. They are 1280×720, which is
below anything generated today, and T01's door and T04's door are different
buildings. Regenerating the set on one door at full resolution fixes both
problems at once. Keep the old clips open beside you while you judge: the set
should look like it came from the same workshop.

**The door is T01's** — the wide green three-bay shopfront. It is written into
every prompt below that needs it.
