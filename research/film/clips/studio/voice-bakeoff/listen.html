Studio voice bake-off

Same lines, different throats. Start with X25 whisper. Score by ear: pass / soft / kill. Winners feed generate-x25-whispers.mjs and later X6 / X8 / X17.

Open via a local server from the repo root, e.g. pnpm exec serve research/film/clips/studio/voice-bakeoff -p 8765 then visit http://localhost:8765/listen.html. Scores save in localStorage only.
